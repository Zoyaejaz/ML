__pycache__
--> is a folder Python automatically creates to store compiled bytecode files (.pyc files).
--> What it does
When you run a Python script:
1. Python compiles your .py file into bytecode (faster to execute)
2. It saves that bytecode inside __pycache__/
3. Next time you run the program, Python can skip recompiling and load the cached version → faster startup

If we have main.py file then in __pycache__, python may create main.cpython-312.pyc,

//Byte code is not machine code
“Bytecode is not a machine because it is only an intermediate set of instructions and cannot execute independently; it requires a virtual machine like the Python Virtual Machine (PVM) to run.”
“Machine code is the binary-level instruction set executed directly by the CPU, whereas bytecode is an intermediate code that requires a virtual machine for execution.”
